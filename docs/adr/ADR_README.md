## Convention

Each ADR has these sections:

- **Context**: the problem and the forces at play
- **Decision**: what was chosen and why
- **Consequences**: positive, negative and neutral outcomes
- **Alternatives Considered**: options that were rejected
- **References**: links to relevant files or documentation

An ADR is immutable once its status is "Accepted". A replaced decision gets a "Superseded by ADR-NNN" line.

## Creating a New ADR

1. Number it in sequence with three digits.
2. Set the status to "Proposed".
3. Add a row to the index above.
